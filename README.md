# Primo Paupérrimo — Investimentos

> Comece com pouco. Invista melhor. Construa seu patrimônio.

O **Primo Paupérrimo** é um projeto experimental de educação financeira e acompanhamento de investimentos para pessoas que começam com pouco dinheiro.

## Objetivo

Partir de um cenário simples:

- R$ 50 de capital inicial
- R$ 50 de aporte mensal
- foco em longo prazo
- comparação entre risco, liquidez e retorno líquido
- possibilidade de recomendar **aportar, manter, aguardar ou reavaliar**

O projeto não promete rentabilidade e não executa ordens de investimento.

## V1

A primeira versão contém:

- painel de patrimônio;
- aporte mensal;
- meta patrimonial;
- projeção matemática;
- regra inicial de alocação;
- estrutura para análise de cenário econômico;
- área para comparação de instituições e produtos.

## Publicação

O site é uma aplicação estática HTML/CSS/JavaScript e pode ser publicado gratuitamente pelo GitHub Pages usando a pasta `docs`.

### GitHub Pages

1. Crie um repositório público chamado `primo-pauperrimo-investimentos`.
2. Envie o conteúdo deste projeto.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/docs`.
6. Salve.

O endereço ficará no formato:

`https://SEU-USUARIO.github.io/primo-pauperrimo-investimentos/`

## Princípios

1. Não gastar dinheiro para começar o projeto.
2. Não confundir investimento com aposta.
3. Comparar retorno líquido, risco e liquidez.
4. O algoritmo pode recomendar não fazer nada.
5. Aumentar os aportes é parte essencial da estratégia.
6. Decisões devem ser explicáveis.

## Aviso

Este projeto tem finalidade educacional e experimental. As informações apresentadas não constituem recomendação individual de investimento. Produtos financeiros, impostos, custos e regras podem mudar; decisões reais devem ser verificadas antes da operação.
